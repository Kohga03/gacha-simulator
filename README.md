# ガチャシミュレーター

## システム概要

ガチャシミュレーターは、ブラウザ上でゲームのガチャを再現したWebアプリケーションです。Dockerコンテナ上で動作し、ブラウザからアクセスしてガチャを引くことができます。

---

## 主な機能

* 1回ガチャ
* 10連ガチャ
* SSR（3%）、SR（17%）、R（80%）の排出率
* ガチャ履歴の表示
* 総ガチャ回数
* SSR排出数
* SSR排出率
* キャラクター一覧
* 各キャラクターの獲得回数表示

---

## 使用技術

* Python
* Flask
* HTML
* CSS
* Bootstrap
* Docker

---

## 実行方法

### Dockerを利用する場合

```bash
docker compose up --build
```

起動後、ブラウザで以下へアクセスします。

```
http://localhost:5000
```

---

### Dockerを利用しない場合

必要ライブラリをインストールします。

```bash
pip install -r requirements.txt
```

実行します。

```bash
python app.py
```

ブラウザで

```
http://localhost:5000
```

へアクセスしてください。

---

## 使い方

1. 「1回ガチャ」または「10連ガチャ」を押します。
2. ガチャ結果が表示されます。
3. ガチャ履歴が更新されます。
4. 総ガチャ回数・SSR排出率が更新されます。
5. キャラクター一覧では各キャラクターを何回引いたか確認できます。
